How to Embed

Add two lines of HTML anywhere on your page. No build step, no npm, no frameworks required.

<script src="https://www.autosafe.one/static/widget.js" defer></script>
<autosafe-widget theme="dark"></autosafe-widget>

That's it. The widget uses Shadow DOM so it won't interfere with your site's CSS.

Frequently Asked Questions

Will it slow down my website?

No. The widget script is under 10KB, loads asynchronously with defer, and makes no API calls until a user clicks "Check". It uses Shadow DOM so it cannot affect your page layout or styles.

What data does it use?

Risk estimates are powered by 142 million official DVSA MOT test records: real failure rates for vehicles of the same make, model and age, broken down by the most common failure areas.

Is it free?

Yes, completely free. The widget includes a "Powered by AutoSafe" link, which helps us continue providing this service. There are no usage fees, no API keys required, and no signup needed.

Does it work on mobile?

Yes. The widget is 320px wide and fully responsive. It renders cleanly on mobile, tablet, and desktop screens.

Do I need to register or get an API key?

No. Just paste the two lines of HTML into your page. The widget works out of the box with no authentication required.

Can I customise the appearance?

The widget supports dark and light themes via the theme attribute. The widget uses Shadow DOM, so its styles are fully encapsulated and won't conflict with your site.
