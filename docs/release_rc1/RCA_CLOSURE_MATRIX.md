## Shared root cause

The five user-visible failures were symptoms of one architectural gap: the
browser lacked a single authoritative contract joining input provenance,
evidence selection, persistence, rendering, identity, and share retrieval.
Secondary privacy and deploy-integrity gaps came from the same split ownership.
RC1 closes that seam with one typed v2 path and makes degraded states explicit.

## Closure rule

“Code closed” means the correction and targeted regression evidence exist. It
does not mean production-ready. Release closure requires the full local suite,
clean Docker/GitHub gates, exact-SHA PostgreSQL and Railway evidence, retention
rehearsals and scheduling, platform privacy inspection, and explicit owner GO.
